Snail Wars is turn based strategy game.

A game made in Godot about snails using weapons to destroy each other.

Controls:
WAD or arrow keys to move
Left mouse button to shot
Scroll wheel to change weapon
Mouse to move the camera

The link to the font I used https://brackeysgames.itch.io/brackeys-platformer-bundle
The link to the bang-sfx I used https://opengameart.org/content/25-cc0-bang-firework-sfx
